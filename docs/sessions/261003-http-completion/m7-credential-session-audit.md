   未确认非空 API key 或密码。另有普通配置、空/掩码和未知分类，均未在本文件展开字段
   内容；一个 shell 工作目录型字段已按普通配置处理，未计为密码。

   provider 验证或服务变更。凭据当前是否仍有效无法由本地会话证明，权限收紧不能替代轮换。
